from collections import Counter
import heapq

def top_k(events, k):
    counts = Counter(events)
    return heapq.nlargest(k, counts, key=counts.get)

✓ handles an empty list

 Trust

      
Know the person on screen did the work.

      
An interview is only useful if the result is real. Presence View protects every session without making the candidate feel watched at every step.

    

    
    
      
  • Locked desktop interview app
    The interview runs in a dedicated desktop app that locks down the environment while it is in progress.
    • 
      
  • Server-side camera checks
    Checks run on the server, not in the candidate’s browser, so they cannot be switched off from the other side.
    • 
      
  • Photo evidence
    Flagged moments come with photo evidence, so a reviewer can look and decide instead of taking a flag on trust.
    • 
      
  • Single-use invites
    Each invite works once, for one candidate, so an interview link cannot be passed around.
